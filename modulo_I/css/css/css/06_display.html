POSICION RELATIVA

Las teclas de un teclado Apple (como el modelo "ice3", que podría ser un Magic Keyboard) tienen dos funciones principales: las teclas de función en la fila superior (\(F1-F12\)) controlan funciones del sistema como el brillo o el volumen, mientras que las teclas modificadoras ($⌘, ⌥, ⇧, Fn, ^$) se usan junto con otras teclas para atajos y comandos. Puedes cambiar el comportamiento de las teclas de función para que sean "estándar" y no requieran mantener presionada la tecla Fn u ` globo terráqueo`, según tus preferencias de uso.  Cortar, copiar, pegar y otras funciones rápidas habituales Comando + X: cortar el elemento seleccionado y copiarlo en el portapapeles. Comando + C: copiar el elemento seleccionado en el portapapeles. Esto también funciona para los archivos del Finder. Comando + V: pegar el contenido del portapapeles en el documento o la app actual. Esto también funciona para los archivos del Finder. Comando + Z: deshacer el comando anterior. Luego, puedes presionar Mayúsculas + Comando + Z para rehacer y así se revierte la acción de deshacer. En algunas apps, puedes deshacer y rehacer varios comandos. Comando + A: seleccionar todos los elementos. Comando + F: buscar elementos en un documento o abrir una ventana de búsqueda. Comando + G: Buscar otra vez: buscar la siguiente aparición del elemento que se encontró anteriormente. Para buscar la aparición anterior, presiona Mayúsculas + Comando + G. Comando + H: ocultar las ventanas de la app activa. Para ver la app activa y ocultar todas las demás apps, presiona Opción + Comando + H. Comando + M: minimizar la ventana activa al Dock. Para minimizar todas las ventanas de la app activa, presiona Opción + Comando + M. Comando + O: abrir el elemento seleccionado o abrir un cuadro de diálogo a fin de seleccionar un archivo para abrir. Comando + P: abrir un cuadro de diálogo de impresión para poder imprimir el documento actual. Comando + Q: salir de la app actual. Comando + S: guardar el documento actual. Comando + T: abrir una pestaña nueva. Comando + W: cerrar la ventana activa. Para cerrar todas las ventanas de la app, presiona Opción + Comando + W. Opción + Comando + Esc: forzar el cierre de una app. Comando + barra espaciadora: mostrar u ocultar el campo de búsqueda de Spotlight. Para realizar una búsqueda de Spotlight desde una ventana del Finder, presiona Opción + Comando + Barra espaciadora. (En algunas versiones de macOS, si usas varias fuentes de entrada para escribir en diferentes idiomas, estas funciones rápidas cambian las fuentes de entrada. Obtén información sobre cómo cambiar una función rápida de teclado conflictiva). Control + Comando + barra espaciadora o Fn + E: mostrar el Visor de caracteres, desde el que se pueden elegir emojis y otros símbolos. Control + Comando + F: usar o dejar de usar la app en pantalla completa, si la app lo admite. Barra espaciadora: usar Vista rápida para obtener una vista previa del elemento seleccionado. Comando + Tabulador: cambiar a la siguiente app usada más recientemente entre las apps abiertas. Comando + acento grave (`): cambiar de ventana de la app que se está usando. (El carácter de la segunda tecla varía según el teclado. Generalmente es la tecla que está sobre la tecla Tabulador y a la izquierda del número 1). Mayúsculas + Comando + 5: en macOS Mojave o versiones posteriores, hacer una captura o grabación de pantalla. O bien, usa Mayúsculas + Comando + 3 o Mayúsculas + Comando + 4 para hacer capturas de pantalla. Obtén más información sobre las capturas de pantalla. Mayúsculas + Comando + N: crear una carpeta nueva vacía en el Finder. Control + Comando + N: crear una nueva carpeta que contenga los elementos seleccionados. Comando + coma (,): abrir la configuración (preferencias) para la app activa. Función + Q: crear una Nota rápida.
